# Icecast Radio Audio Streamer

Stream directly from YouTube / audio sources straight into your **Icecast** server without downloading files or using Discord.

---

## 1. How It Works

```
[YouTube Query / URL]
        │
        ▼
   1. yt-dlp
      - Resolves audio metadata & direct stream URL
        │
        ▼
   2. FFmpeg
      - Reads direct remote stream URL (-reconnect 1)
      - Transcodes live into MP3 (libmp3lame) or Ogg Opus
      - Streams real-time (-re) directly into Icecast mountpoint
        │
        ▼
   [Icecast Server: icecast://source:password@host:port/mount]
        │
        ▼
   Listeners (Web player, VLC, Radio receiver, mobile app)
```

---

## 2. Standalone Python Script (`icecast_streamer.py`)

Here is a ready-to-use Python script that resolves any song/stream and broadcasts it directly to your Icecast server:

```python
import os
import subprocess
import yt_dlp

# --- Icecast Configuration ---
ICECAST_HOST = "localhost"       # or your radio server IP/domain
ICECAST_PORT = 8000
ICECAST_MOUNT = "/live"          # your mountpoint (e.g., /live, /radio.mp3)
ICECAST_SOURCE_PASS = "hackme"   # your Icecast source password
ICECAST_FORMAT = "mp3"           # "mp3" or "opus" / "ogg"
BITRATE = "192k"                 # 128k, 192k, 320k
FFMPEG_PATH = "ffmpeg"           # or "./ffmpeg.exe" if local


def extract_stream_info(query: str):
    """
    Extracts direct audio stream URL and HTTP headers from YouTube.
    """
    ydl_opts = {
        "format": "bestaudio/best",
        "noplaylist": True,
        "quiet": True,
        "no_warnings": True,
        "default_search": "ytsearch1",
        "socket_timeout": 20,
        "retries": 3,
        "cachedir": False,
    }

    with yt_dlp.YoutubeDL(ydl_opts) as ydl:
        info = ydl.extract_info(query, download=False)

    if "entries" in info:
        info = next((e for e in info["entries"] if e), None)

    if not info or not info.get("url"):
        raise RuntimeError("No playable audio stream found.")

    return {
        "title": info.get("title", "Unknown Title"),
        "stream_url": info.get("url"),
        "headers": info.get("http_headers", {}),
    }


def stream_to_icecast(query: str):
    print(f"Resolving stream for: {query}...")
    track = extract_stream_info(query)
    print(f"Now Streaming to Icecast: {track['title']}")

    # Build Icecast destination URL
    icecast_url = (
        f"icecast://source:{ICECAST_SOURCE_PASS}@{ICECAST_HOST}:{ICECAST_PORT}{ICECAST_MOUNT}"
    )

    # Format HTTP headers for FFmpeg
    headers_str = "".join([f"{k}: {v}\r\n" for k, v in track["headers"].items()])

    # FFmpeg command:
    # -re               : Read input in native frame-rate (real-time stream)
    # -reconnect 1      : Auto-reconnect if YouTube CDN connection drops
    # -c:a libmp3lame   : Transcode to MP3 on-the-fly
    # -content_type     : MIME type for Icecast server
    # -f mp3            : Format
    ffmpeg_cmd = [
        FFMPEG_PATH,
        "-headers", headers_str,
        "-re",
        "-reconnect", "1",
        "-reconnect_streamed", "1",
        "-reconnect_delay_max", "5",
        "-i", track["stream_url"],
        "-vn",
        "-c:a", "libmp3lame",
        "-b:a", BITRATE,
        "-content_type", "audio/mpeg",
        "-f", "mp3",
        icecast_url
    ]

    process = subprocess.Popen(ffmpeg_cmd)
    try:
        process.wait()
    except KeyboardInterrupt:
        print("\nStopping stream...")
        process.terminate()


if __name__ == "__main__":
    # Example song or live stream URL / search query
    stream_to_icecast("lofi hip hop radio beats to relax/study to")
```

## 3. Direct Command Line (One-Liner)

If you already extracted the stream URL via `yt-dlp` in your terminal:

```powershell
# 1. Get direct stream URL using yt-dlp
$URL = $(yt-dlp -g -f bestaudio "ytsearch1:lofi hip hop radio")

# 2. Pipe directly to Icecast
ffmpeg -re -reconnect 1 -reconnect_streamed 1 -i "$URL" -vn -c:a libmp3lame -b:a 192k -content_type audio/mpeg -f mp3 "icecast://source:hackme@localhost:8000/live"
```

## 4. Continuous Radio Loop / Playlist

To make it an uninterrupted radio station that plays a queue:

```python
import time

playlist = [
    "lofi hip hop radio",
    "synthwave radio chill beats",
    "jazz radio relaxing music"
]

for track_query in playlist:
    try:
        stream_to_icecast(track_query)
    except Exception as e:
        print(f"Track failed: {e}")
        time.sleep(2)
```
